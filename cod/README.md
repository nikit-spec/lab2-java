# Лабораторная работа № 2

Вариант 3

## Цель

Понять, как в Java создавать объекты, использовать конструкторы с разными параметрами и выводить данные через `toString()`.

## Ход работы

Все задания находятся в одном проекте. Для имени, человека, города и кота я сделал отдельные классы. Примеры запускаются из `main`, данные я ввожу с клавиатуры.

1.3 и 4.5. Класс `Name` хранит личное имя, фамилию и отчество. У него три конструктора. Можно указать только имя, имя и фамилию или все три части. Пустые части в выводе пропускаются. В последнем примере Бонифатьевич записан как фамилия.

```text
Клеопатра
Пушкин Александр Сергеевич
Маяковский Владимир
Бонифатьевич Христофор
```

2.2. Я использовал первые три объекта `Name` из 1.3, чтобы создать людей. После ввода роста программа вывела «Клеопатра, 152», «Пушкин Александр Сергеевич, 167» и «Маяковский Владимир, 189».

2.3. При создании Петра я передал Ивана как отца, а при создании Бориса передал Петра. Если фамилия пустая, программа берёт её у отца. Чтобы заполнить пустое отчество, она прибавляет «ович» к имени отца. Рост в этом примере не указан в условии, поэтому я ввёл 175, 178 и 180 см. У Бориса было только личное имя. Программа вывела «Чудов Борис Петрович, 180».

3.3. Каждый город хранит название и стоимость поездок в соседние города. В программе задана схема дорог из рисунка 2. При запуске я ввёл названия A, B, C, D, E, F и цены 5, 6, 1, 3, 4, 2, 2, 1 в порядке запросов. У пяти дорог есть обратное направление, поэтому всего получилось 13 направлений.

```text
A → [B:5, D:6, F:1]
B → [A:5, C:3]
C → [B:3, D:4]
D → [A:6, C:4, E:2]
E → [F:2]
F → [E:2, B:1]
```

4.6. У класса `Person` четыре конструктора. Имя можно передать строкой или объектом `Name`, с отцом или без него. Все поля задаются в одном конструкторе, остальные вызывают его через `this(...)`. Для Льва и Александра я передал имя строкой, а для Сергея передал объект `Name`. Отчества получились по правилу из 2.3.

```text
Лев, 170
Пушкин Сергей Левович, 168
Пушкин Александр Сергейович, 167
```

5.2. У класса `Cat` два метода `meow`. Первый печатает одно «мяу», второму можно передать число повторов. Для проверки я ввёл Барсик и 3.

```text
кот: Барсик
Барсик: мяу!
Барсик: мяу-мяу-мяу!
```

## Проверка ввода

Если оставить фамилию или отчество пустыми, программа их пропускает. При трёх пустых частях она запрашивает имя заново. Я также проверил нулевой рост, текст вместо числа и отрицательную цену. Во всех случаях программа повторила запрос числа.

## Вывод

Я использовал один класс `Person` в заданиях с именем и с отцом. Для этого передавал в конструктор уже созданные объекты. Свой вывод для каждого класса сделал через `toString()`.

## Запуск

Команды выполняются из папки проекта. Нужен JDK 17 или новее.

```shell
javac --release 17 -encoding UTF-8 -d out -sourcepath src src/Main.java
java -cp out Main
```
