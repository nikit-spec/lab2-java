# Отчёт по лабораторной работе № 2

Вариант 3

## Ход работы

В `Main` каждое значение читается целой строкой через `Scanner.nextLine()`. Пробелы по краям убираются. Если обязательное поле пустое, программа запрашивает его заново. Рост, цена и число мяуканий преобразуются в целые числа через `Integer.parseInt()`. Если преобразование не удаётся или число меньше допустимого, запрос повторяется.

1.3 и 4.5. В классе `Name` имя хранится в трёх полях. После ввода сначала проверяется отчество. Если оно заполнено, в конструктор передаются три строки. Если отчество пустое, но есть фамилия, передаются две. Для одного личного имени вызывается конструктор с одним параметром. Короткие конструкторы передают пустые строки за пропущенные части и вызывают общий конструктор через `this(...)`. Если все три поля пустые, общий конструктор сообщает об ошибке и ввод повторяется. В `toString()` сначала соединяются фамилия и имя, затем убираются пробелы по краям. После этого добавляется отчество и снова убираются крайние пробелы. Поэтому при пустых фамилии и отчестве выводится только «Клеопатра».

2.2. Первые три объекта `Name` сохраняются в массиве. В следующем цикле из массива берётся готовое имя, запрашивается рост этого человека и оба значения передаются в `new Person(name, height)`. В поле `name` хранится объект `Name`. При печати человека сначала вызывается `toString()` у имени, затем к полученной строке добавляются запятая и рост. Так из объекта имени Пушкина и введённого числа 167 получается «Пушкин Александр Сергеевич, 167».

2.3. Сначала создаётся Иван. При создании Петра в конструктор передаётся ссылка на Ивана как на отца. Затем таким же способом Пётр передаётся при создании Бориса. Если отец указан, конструктор `Person` вызывает `withFather()` и передаёт в него имя отца. Метод отдельно проверяет фамилию и отчество. Пустая фамилия берётся у отца. Если отчество пустое и у отца есть личное имя, к этому имени добавляется «ович». Из полученных частей создаётся новый `Name` для ребёнка. У Бориса введено только личное имя, поэтому фамилия берётся у Петра, а отчество образуется из его имени. Программа выводит «Чудов Борис Петрович, 180». Рост 180 см введён для примера, поскольку в условии он не указан.

3.3. Сначала создаются шесть объектов `City`. У каждого своя коллекция `Map<City, Integer>`, в которой цена поездки хранится по объекту соседнего города. Метод `readRoad()` читает цену и вызывает `addRoute()` у города отправления. Этот метод добавляет пару в коллекцию через `put()`. Если дорога двусторонняя, у города назначения добавляется обратный маршрут с той же ценой. Для A ↔ B записи появляются в обоих городах, а для A → F запись появляется только у A. В `toString()` перебираются соседние города, к их названиям добавляются цены из коллекции. Например, для A получается `A → [B:5, D:6, F:1]`.

4.6. Конструкторы `Person` принимают имя строкой или объектом `Name`. Из строки сначала создаётся `Name` с одним личным именем. Готовый `Name` передаётся сразу. В вариантах без отца передаётся `null`. Три конструктора вызывают общий конструктор через `this(...)`. Общий конструктор сохраняет отца и рост и при необходимости дополняет имя. Например, имя Александр передаётся строкой. После преобразования в `Name` остаётся только личное имя, поэтому фамилия Пушкин берётся у Сергея, а отчество образуется добавлением «ович» к имени Сергей.

5.2. Печать выполняется в методе `meow(int times)` класса `Cat`. Метод без параметра вызывает его с числом 1. Сначала печатаются имя кота и одно «мяу», поэтому счётчик цикла начинается с 1. Пока счётчик меньше `times`, дописываются дефис и ещё одно «мяу». После цикла печатаются восклицательный знак и перевод строки. При числе 3 цикл делает два прохода, и вместе с первым «мяу» получается `Барсик: мяу-мяу-мяу!`.
